workspaces support for COSMIC DE

Cosmic-workspaces Dependencies

Required

rustc, cargo-c, mesa, wayland, libxkbcommon, libinput, and cosmic-icons

2.22.1. Installation of Cosmic-workspaces

Prepare Cosmic-workspaces for compilation:

Fetch the dependencies, ensuring the exact versions recorded in the existing Cargo.lock file are used: 

cargo fetch --locked

To Compile the Package, issue: 

cargo build --release

Now Install the Package, issue: 

install -vDm755 target/release/cosmic-workspaces /usr/bin/cosmic-workspaces &&

install -vDm644 data/com.system76.CosmicWorkspaces.desktop \
  /usr/share/applications/com.system76.CosmicWorkspaces.desktop &&

install -vDm644 data/com.system76.CosmicWorkspaces.svg \
  /usr/share/icons/hicolor/scalable/apps/com.system76.CosmicWorkspaces.svg
