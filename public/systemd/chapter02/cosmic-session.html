2.30.1. Installation of Cosmic-session

Prepare Cosmic-session for compilation:

Fetch the dependencies, ensuring the exact versions recorded in the existing Cargo.lock file are used: 

sed -i "s|DCONF_PROFILE=cosmic|DCONF_PROFILE=/usr/share/dconf/profile/cosmic|" data/start-cosmic &&
cargo fetch --locked

To Compile the Package, issue: 

export XDP_COSMIC="/usr/libexec/xdg-desktop-portal-cosmic" &&
cargo build --release

Now Install the Package, issue: 

install -vDm755 target/release/cosmic-session /usr/bin/cosmic-session &&
install -vDm755 data/start-cosmic /usr/bin/ &&

install -vDm644 data/cosmic-session.target /usr/lib/systemd/user/cosmic-session.target &&

install -vDm644 data/cosmic.desktop /usr/share/wayland-sessions/cosmic.desktop &&

install -vDm644 data/cosmic-mimeapps.list /usr/share/applications/cosmic-mimeapps.list &&
install -vDm644 debian/cosmic-session.gsettings-override \
  /usr/share/glib-2.0/schemas/50_cosmic-session.gschema.override &&
install -vDm644 data/dconf/profile/cosmic /usr/share/dconf/profile/cosmic
glib-compile-schemas /usr/share/glib-2.0/schemas
