2.13. Cosmic-randr-1.11.0

CLI utility for displaying and configuring wayland outputs from COSMIC DE

  • Download SHA256 Sum: e85ff56ef0f8168dccc4133ff5a0efa35233712331b406cca1cf628db6774de9

  • Download Size: 6,677 KB

  • Estimated Disk Space: 286.9M

  • Estimated Build Time: less than 0.5 SBU

Cosmic-randr Dependencies

Required

rustc, cargo-c, and wayland

2.13.1. Installation of Cosmic-randr

Prepare Cosmic-randr for compilation:

To Build the Package, issue: 

cargo build --release

Now Install the Package, issue: 

install -vm755 target/release/cosmic-randr /usr/bin/cosmic-randr
