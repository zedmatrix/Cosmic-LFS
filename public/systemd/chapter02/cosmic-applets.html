2.4.1. Installation of Cosmic-applets

Prepare Cosmic-applets for compilation:

Now Configure the Package, issue: 

sed "s|@bindir@|${EPREFIX}/usr/bin|" \
  cosmic-applet-status-area/data/dbus-1/com.system76.CosmicStatusNotifierWatcher.service.in \
  > cosmic-applet-status-area/data/dbus-1/com.system76.CosmicStatusNotifierWatcher.service &&

sed "s|@bindir@|${EPREFIX}/usr/bin|" \
  cosmic-applet-status-area/data/com.system76.CosmicStatusNotifierWatcher.service.in \
  > cosmic-applet-status-area/data/com.system76.CosmicStatusNotifierWatcher.service &&

cargo fetch --locked

To Compile the Package, issue: 

cargo build --release --frozen

Now Install the Package, issue: 

install -vDm755 target/release/cosmic-applets /usr/bin/cosmic-applets &&

install -vDm644 cosmic-applet-status-area/data/com.system76.CosmicStatusNotifierWatcher.service \
  /usr/lib/systemd/user/com.system76.CosmicStatusNotifierWatcher.service &&

install -vDm644 cosmic-applet-status-area/data/dbus-1/com.system76.CosmicStatusNotifierWatcher.service \
  /usr/share/dbus-1/services/com.system76.CosmicStatusNotifierWatcher.service &&

install -vDm644 data/com.system76.CosmicApplets.metainfo.xml /usr/share/metainfo &&

cp -rv cosmic-app-list/data/default_schema/* /usr/share/cosmic/

Now, as the root user, create the symlinks to the multicall binary, install the icons, and install the desktop files: 

for applet in cosmic-app-list cosmic-applet-a11y cosmic-applet-audio \
    cosmic-applet-battery cosmic-applet-bluetooth \
    cosmic-applet-input-sources cosmic-applet-minimize \
    cosmic-applet-network cosmic-applet-notifications \
    cosmic-applet-osk cosmic-applet-power \
    cosmic-applet-status-area cosmic-applet-tiling \
    cosmic-applet-time cosmic-applet-workspaces \
    cosmic-panel-button
do
  ln -sfrv /usr/bin/cosmic-applets /usr/bin/$applet
done

for dir in cosmic-app-list cosmic-applet-a11y cosmic-applet-audio \
    cosmic-applet-battery cosmic-applet-bluetooth \
    cosmic-applet-input-sources cosmic-applet-minimize \
    cosmic-applet-network cosmic-applet-notifications \
    cosmic-applet-osk cosmic-applet-power \
    cosmic-applet-status-area cosmic-applet-tiling \
    cosmic-applet-time cosmic-applet-workspaces \
    cosmic-panel-app-button cosmic-panel-launcher-button \
    cosmic-panel-workspaces-button
do
  if [ -d $dir/data/icons ]; then
    cp -rv $dir/data/icons/* /usr/share/icons/hicolor
  fi
done

Note

Verify that the build generated the desktop files for all 18 applets and buttons. The following command should print 18: 

ls target/xdgen/*.desktop | wc -l
install -vDm644 target/xdgen/*.desktop /usr/share/applications/
