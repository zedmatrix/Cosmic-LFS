Cosmic-app-library Dependencies

Required

rustc cargo-c

2.3.1. Installation of Cosmic-app-library

Prepare Cosmic-app-library for compilation:

Now Configure the Package, issue: 

cargo fetch --locked

To Compile the Package, issue: 

export LOCKSTEP_XML_PATH="${PWD}/vendor/atspi-common/xml"
cargo build --release --offline

Now Install the Package, issue: 

install -vDm755 target/release/cosmic-app-library /usr/bin/cosmic-app-library

install -vDm644 data/com.system76.CosmicAppLibrary.desktop \
  /usr/share/applications/com.system76.CosmicAppLibrary.desktop

install -vDm644 data/com.system76.CosmicAppLibrary.metainfo.xml \
  /usr/share/metainfo/

cp -v data/icons/com.system76.CosmicAppLibrary.svg /usr/share/icons/hicolor/scalable/apps/
