2.29. Pop-fonts-master

System76 primarily uses two fonts, Fira and Roboto Slab.

Package Information

  • Download GIT URL: https://github.com/pop-os/fonts.git

  • Download Size: 77,175 KB

  • Estimated Disk Space: 101.1M

  • Estimated Build Time: less than 0.1 SBU

Pop-fonts Dependencies

Required

fontconfig, and git

2.29.1. Installation of Pop-fonts

Prepare Pop-fonts by cloning the repo: 

git clone https://github.com/pop-os/fonts.git pop-fonts &&
cd pop-fonts

Now Install the fonts by copying: 

cp --no-preserve=mode,ownership -rv fira /usr/share/fonts/ &&
cp --no-preserve=mode,ownership -rv roboto-slab /usr/share/fonts/

Now Update the font cache, issue: 

fc-cache -v /usr/share/fonts/fira &&
fc-cache -v /usr/share/fonts/roboto-slab

2.29.2. Contents of Pop-fonts

Installed programs: None
Installed libraries: None
Installed directories: /usr/share/fonts/{roboto-slab, fira}
