Cosmic-initial-setup Dependencies

2.23.1. Installation of Cosmic-initial-setup

Prepare Cosmic-initial-setup for compilation:

Fetch the dependencies, ensuring the exact versions recorded in the existing Cargo.lock file are used: 

cargo fetch --locked

To Compile the Package, issue: 

cargo build --profile release --frozen

Now Install the Package, issue: 

install -vDm755 target/release/cosmic-initial-setup \
        /usr/bin/cosmic-initial-setup &&

install -vDm644 res/*.desktop /usr/share/applications/ &&

install -vdm755 /etc/xdg/autostart &&

install -vDm644 res/com.system76.CosmicInitialSetup.Autostart.desktop \
  /etc/xdg/autostart/com.system76.CosmicInitialSetup.desktop &&

install -vDm644 res/icon.svg \
  /usr/share/icons/hicolor/scalable/apps/com.system76.CosmicInitialSetup.svg &&

install -vdm755 /usr/share/cosmic-layouts &&

cp -rv res/layouts/* /usr/share/cosmic-layouts &&

install -vdm755 /usr/share/cosmic-themes &&

cp -rv res/themes/* /usr/share/cosmic-themes
