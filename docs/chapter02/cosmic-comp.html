Cosmic-comp Dependencies

Required

fontconfig, mesa, libxcb, pixman, libdisplay-info, seatd, libinput, libxcb, libxkbcommon, wayland, and wayland-protocols

2.6.1. Installation of Cosmic-comp

Prepare Cosmic-comp for compilation:

To Build the Package, issue: 

cargo build --release

Now Install the Package, issue: 

install -vDm755 target/release/cosmic-comp /usr/bin/cosmic-comp &&

install -vDm644 data/keybindings.ron \
  /usr/share/cosmic/com.system76.CosmicSettings.Shortcuts/v1/defaults &&

install -vDm644 data/tiling-exceptions.ron \
  /usr/share/cosmic/com.system76.CosmicSettings.WindowRules/v1/tiling_exception_defaults

Installed programs: cosmic-comp

Installed directories: /usr/bin, and /usr/share/cosmic
