Modular IPC-based desktop launcher service

Pop-launcher Dependencies

Required

rustc, cargo-c, libqalculate, dbus, mesa, libxkbcommon, xdg-utils, and pop-icon-theme

2.24.1. Installation of Pop-launcher

Prepare Pop-launcher for compilation:

Now Configure the Package, issue: 

cargo fetch --locked

To Compile the Package, issue: 

cargo build --release -p pop-launcher-bin

Now Install the Package, issue: 

install -vDm755 target/release/pop-launcher-bin /usr/bin/pop-launcher &&

(cd scripts && find . -type f -exec install -Dm755 {} /usr/share/pop-launcher/scripts/{} \;) &&

for p in calc cosmic_toplevel desktop_entries files find pop_shell pulse recent scripts terminal web; do
  install -vdm755 "/usr/lib/pop-launcher/plugins/$p"
  install -vm644 plugins/src/"$p"/*.ron "/usr/lib/pop-launcher/plugins/$p"/
  ln -vsfr /usr/bin/pop-launcher "/usr/lib/pop-launcher/plugins/$p/${p/_/-}"
done

2.24.2. Contents of Pop-launcher

Installed programs: pop-launcher, (plugin links calc, cosmic_toplevel, desktop_entries, files, find, pop_shell, pulse, recent, scripts, terminal, and web)
Installed libraries: None
Installed directories: /usr/bin, /usr/share/pop-launcher/scripts, and /usr/lib/pop-launcher/plugins
