2.7. Cosmic-term-1.11.0

terminal emulator (built using alacritty_terminal) from COSMIC DE

Package Information

  • Download HTTP: https://github.com/fsvm88/cosmic-overlay/releases/download/1.11.0/cosmic-term-1.11.0.full.tar.zst

  • Download SHA256 Sum: e1fe63358cf6ee4284125ce49a5379d163395c6aec9338311a491e76df4a17b7

  • Download Size: 75,712 KB

  • Estimated Disk Space: 3.2G

  • Estimated Build Time: 3.54 SBU

Cosmic-term Dependencies

Required

rustc, cargo-c, cosmic-icons, wayland, and libxkbcommon

2.7.1. Installation of Cosmic-term

Prepare Cosmic-term for compilation:

To Build the Package, issue: 

export VERGEN_GIT_COMMIT_DATE='Tue Oct 20 13:46:25 2026 -0600' &&
export VERGEN_GIT_SHA=699ac42384b917029082d45a01a9261a4ba75c45 &&

cargo build --release --offline

Now Install the Package, issue: 

install -vDm755 target/release/cosmic-term /usr/bin/cosmic-term &&

install -vDm644 target/xdgen/com.system76.CosmicTerm.desktop \
  /usr/share/applications/com.system76.CosmicTerm.desktop &&
install -vDm644 target/xdgen/com.system76.CosmicTerm.metainfo.xml \
  /usr/share/metainfo/com.system76.CosmicTerm.metainfo.xml &&

cp -rv res/icons/hicolor/. /usr/share/icons/hicolor/
unset VERGEN_GIT_COMMIT_DATE VERGEN_GIT_SHA &&
gtk-update-icon-cache -qtf /usr/share/icons/hicolor

2.7.2. Contents of Cosmic-term

Installed programs: cosmic-term
Installed libraries: LIBRARIES
Installed directories: /usr/bin, /usr/share/icons, /usr/share/metainfo, and /usr/share/applications
