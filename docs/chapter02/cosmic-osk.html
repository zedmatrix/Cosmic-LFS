Cosmic-osk Dependencies

Required

rustc, cargo-c, libxkbcommon, and wayland

2.17.1. Installation of Cosmic-osk

Prepare Cosmic-osk for compilation:

Fetch the dependencies, ensuring the exact versions recorded in the existing Cargo.lock file are used: 

cargo fetch --locked

To Compile the Package, issue: 

cargo build --profile release --frozen --all

Now Install the Package, issue: 

install -vDm755 target/release/cosmic-osk /usr/bin/cosmic-osk
