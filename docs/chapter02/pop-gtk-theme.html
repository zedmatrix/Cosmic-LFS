PopOS GTK theme for COSMIC DE

  • Download Size: 3,132 KB

  • Estimated Disk Space: 15.1M

  • Estimated Build Time: less than 0.5 SBU

  • Required patch: https://raw.githubusercontent.com/fsvm88/cosmic-overlay/main/cosmic-base/pop-gtk-theme/files/remove-gtk2-gtk3.patch

Pop-gtk-theme Dependencies

Required

rustc, cargo-c, meson, ninja, sassc, glib, gdk-pixbuf, and gtk4

2.28.1. Installation of Pop-gtk-theme

Prepare Pop-gtk-theme for compilation:

Patch a vulnerability, issue: 

patch -Np1 -i ../remove-gtk2-gtk3.patch

Now Configure the Package, issue: 

meson setup Ybuild --prefix=/usr --buildtype=release \
            -D icons=true -D gnome-shell=true \
            -D gnome-shell-gresource=true     \
            -D gtk4=true -D sounds=true       \
            -D sessions=true -D default=true  \
            -D dark=true -D light=true

To Compile the Package, issue: 

ninja -C Ybuild

Now Install the Package, issue: 

ninja -C Ybuild install

2.28.2. Contents of Pop-gtk-theme

Installed programs: None
Installed libraries: None
Installed directories: /usr/share/sounds, /usr/share/themes, and /usr/share/gnome-shell/theme
