Xdg-desktop-portal-cosmic Dependencies

Required

rustc, cargo-c, mesa, pipewire, libxkbcommon, wayland, xdg-desktop-portal, and cosmic-icons

2.18.1. Installation of Xdg-desktop-portal-cosmic

Prepare Xdg-desktop-portal-cosmic for compilation:

Now Configure the Package, issue: 

sed -i 's|@libexecdir@/|/usr/libexec/|' \
  data/org.freedesktop.impl.portal.desktop.cosmic.service.in \
  data/dbus-1/org.freedesktop.impl.portal.desktop.cosmic.service.in

To Compile the Package, issue: 

export VERGEN_GIT_COMMIT_DATE='Tue Oct 20 13:45:17 2026 -0600' &&
export VERGEN_GIT_SHA=f448ddfb296bf7bb23517b24b2f532559a334a1c &&
cargo build --release --no-default-features

Now Install the Package, issue: 

install -vDm755 target/release/xdg-desktop-portal-cosmic \
        /usr/libexec/xdg-desktop-portal-cosmic &&

install -vDm644 data/org.freedesktop.impl.portal.desktop.cosmic.service.in \
  /usr/lib/systemd/user/org.freedesktop.impl.portal.desktop.cosmic.service &&

install -vDm644 data/dbus-1/org.freedesktop.impl.portal.desktop.cosmic.service.in \
  /usr/share/dbus-1/services/org.freedesktop.impl.portal.desktop.cosmic.service &&

install -vDm644 data/cosmic.portal /usr/share/xdg-desktop-portal/portals &&

install -vDm644 data/cosmic-portals.conf /usr/share/xdg-desktop-portal &&

cp -rv data/icons/. /usr/share/icons/hicolor/
