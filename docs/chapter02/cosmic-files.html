file manager from COSMIC DE

Package Information

  • Download SHA256 Sum: afe7ac595c1adbc4a9fd144867df274c4c8fed60a5e9161742aacc59ccaae38b

  • Download Size: 87,620 KB

  • Estimated Disk Space: 4.6G

  • Estimated Build Time: 5.97 SBU

Cosmic-files Dependencies

Required

rustc, cargo-c, glib, xdg-utils, gvfs, cosmic-icons, and libxkbcommon

2.8.1. Installation of Cosmic-files

To Prepare the Package, issue:

Fetch the dependencies, ensuring the exact versions recorded in the existing Cargo.lock file are used: 

cargo fetch --locked

To Build the Package, issue: 

export VERGEN_GIT_COMMIT_DATE='Tue Oct 20 17:40:58 2026 +0200' &&
export VERGEN_GIT_SHA=3cc4b8003e8d08349c7ced8a9cdd10cdfa45d38c &&
export LOCKSTEP_XML_PATH="${PWD}/vendor/atspi-common/xml" &&

cargo build --release
cargo build --release --package cosmic-files-applet
cargo build --release --package cosmic-files-thumbnailer

Now Install the Package, issue: 

install -vDm755 target/release/cosmic-files /usr/bin/cosmic-files &&
install -vDm755 target/release/cosmic-files-applet /usr/bin/cosmic-files-applet &&
install -vDm755 target/release/cosmic-files-thumbnailer /usr/bin/cosmic-files-thumbnailer &&

install -vDm644 target/xdgen/com.system76.CosmicFiles.desktop \
  /usr/share/applications/ &&

install -vDm644 target/xdgen/com.system76.CosmicFiles.metainfo.xml \
  /usr/share/metainfo/ &&

install -vDm644 res/com.system76.CosmicFiles.thumbnailer \
  /usr/share/thumbnailers &&

cp -rv res/icons/hicolor/* /usr/share/icons/hicolor/

unset VERGEN_GIT_COMMIT_DATE VERGEN_GIT_SHA LOCKSTEP_XML_PATH

Installed libraries: None
Installed directories: /usr/bin, /usr/share/icons/hicolor, /usr/share/thumbnailers, /usr/share/metainfo, and /usr/share/applications
