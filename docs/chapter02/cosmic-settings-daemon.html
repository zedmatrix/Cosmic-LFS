settings daemon for the COSMIC DE

Cosmic-settings-daemon Dependencies

Required

rustc, cargo-c, cosmic-sound-theme, libinput, pipewire, pulseaudio, wireplumber, xdg-utils, libxkbcommon, and alsa-utils

2.26.1. Installation of Cosmic-settings-daemon

Prepare Cosmic-settings-daemon for compilation:

Fetch the dependencies, ensuring the exact versions recorded in the existing Cargo.lock file are used: 

cargo fetch --locked

To Compile the Package, issue: 

cargo build --profile release --frozen

Now Install the Package, issue: 

install -vDm755 target/release/cosmic-settings-daemon \
        /usr/bin/cosmic-settings-daemon &&

install -vDm644 data/system_actions.ron \
  /usr/share/cosmic/com.system76.CosmicSettings.Shortcuts/v1/system_actions &&

install -vDm644 data/polkit-1/rules.d/cosmic-settings-daemon.rules \
  /usr/share/polkit-1/rules.d/
