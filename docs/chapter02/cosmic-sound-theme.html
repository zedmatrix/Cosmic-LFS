2.20.1. Installation of Cosmic-sound-theme

Prepare Cosmic-sound-theme for compilation:

Change the theme name so we don't have to use the installer, issue: 

sed -e 's/@ThemeName@/COSMIC/' src/index.theme.in > src/index.theme

Now Install the Package, issue: 

mkdir -pv /usr/share/sounds/COSMIC &&

cp -v src/index.theme /usr/share/sounds/COSMIC &&
cp -rv src/stereo/. /usr/share/sounds/COSMIC/
