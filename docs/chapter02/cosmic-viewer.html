2.10. Cosmic-viewer-1.11.0

image viewer for COSMIC DE

  • Download SHA256 Sum: fcc64d1d2f3e97cc7a01b1d9b5e6a70af8a7b3139cecc1360ed4b80c0a653120

  • Download Size: 82,701 KB

  • Estimated Disk Space: 2.8G

  • Estimated Build Time: 3.26 SBU

Cosmic-viewer Dependencies

Required

rustc, cargo-c, libheif, hicolor-icon-theme, libjpeg-turbo, libxkbcommon, libde265, and dav1d

2.10.1. Installation of Cosmic-viewer

Prepare Cosmic-viewer for compilation:

Now Configure the Package, issue: 

sed -i -e '/^  "embedded-libheif",$/d' Cargo.toml &&
cargo update --offline --workspace

To Build the Package, issue: 

export TURBOJPEG_SOURCE=pkg-config &&
export TURBOJPEG_DYNAMIC=1 &&

cargo build --release --offline

Now Install the Package, issue: 

install -vDm755 target/release/cosmic-viewer /usr/bin/cosmic-viewer &&

install -vDm644 res/com.system76.CosmicViewer.desktop \
  /usr/share/applications/com.system76.CosmicViewer.desktop &&

install -vDm644 res/com.system76.CosmicViewer.metainfo.xml \
  /usr/share/metainfo/com.system76.CosmicViewer.metainfo.xml &&

cp -rv res/icons/hicolor/. /usr/share/icons/hicolor/

gtk-update-icon-cache -qtf /usr/share/icons/hicolor
