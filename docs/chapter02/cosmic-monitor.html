Cosmic-monitor Dependencies

Required

rustc, cargo-c, and libxkbcommon

2.14.1. Installation of Cosmic-monitor

Prepare Cosmic-monitor for compilation:

Fetch the dependencies, ensuring the exact versions recorded in the existing Cargo.lock file are used: 

cargo fetch --locked

To Compile the Package, issue: 

cargo build --profile release

Now Install the Package, issue: 

install -vDm755 target/release/cosmic-monitor /usr/bin/cosmic-monitor &&

install -vDm644 target/xdgen/com.system76.CosmicMonitor.desktop \
  /usr/share/applications/ &&

install -vDm644 target/xdgen/com.system76.CosmicMonitor.metainfo.xml \
  /usr/share/metainfo/ &&

cp -rv res/icons/hicolor/* /usr/share/icons/hicolor/
