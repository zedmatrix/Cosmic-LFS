Cosmic-launcher Dependencies

2.25.1. Installation of Cosmic-launcher

Prepare Cosmic-launcher for compilation:

Fetch the dependencies, ensuring the exact versions recorded in the existing Cargo.lock file are used: 

cargo fetch --locked

To Compile the Package, issue: 

export LOCKSTEP_XML_PATH=${PWD}/vendor/atspi-common/xml &&

cargo build --release

Now Install the Package, issue: 

install -vDm755 target/release/cosmic-launcher /usr/bin/cosmic-launcher &&

install -vDm644 data/com.system76.CosmicLauncher.desktop \
  /usr/share/applications/com.system76.CosmicLauncher.desktop &&

install -vDm644 data/com.system76.CosmicLauncher.metainfo.xml \
  /usr/share/metainfo/com.system76.CosmicLauncher.metainfo.xml &&

install -vDm644 data/icons/com.system76.CosmicLauncher.svg \
  /usr/share/icons/hicolor/scalable/apps/com.system76.CosmicLauncher.svg
