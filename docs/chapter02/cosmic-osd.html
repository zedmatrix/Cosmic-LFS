Cosmic-osd Dependencies

Required

rustc, cargo-c, libinput, pipewire, pulseaudio, libxkbcommon, wayland, and sound-theme-freedesktop

2.16.1. Installation of Cosmic-osd

Prepare Cosmic-osd for compilation:

Fix the installed directories and fetch the dependencies, ensuring the exact versions recorded in the existing Cargo.lock file are used: 

sed -i 's|.unwrap_or("/usr/libexec/polkit-agent-helper-1")|.unwrap_or("/usr/lib/polkit-1/polkit-agent-helper-1")|' \
  src/subscriptions/polkit_agent_helper.rs &&

cargo fetch --locked

To Compile the Package, issue: 

cargo build --profile release --frozen

Now Install the Package, issue: 

install -vm755 target/release/cosmic-osd /usr/bin/cosmic-osd
