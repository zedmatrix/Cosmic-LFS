2.27.1. Installation of Cosmic-settings

Prepare Cosmic-settings for compilation:

Fetch the dependencies, ensuring the exact versions recorded in the existing Cargo.lock file are used: 

cargo fetch --locked

To Compile the Package, issue: 

cargo build --profile release --no-default-features --features \
 "a11y avif cosmic-comp-config page-accessibility page-about page-bluetooth page-date page-default-apps \
 page-display page-input page-legacy-applications page-networking page-power page-region page-sound \
 page-window-management page-workspaces systemd xdg-portal wayland single-instance wgpu"

Now Install the Package, issue: 

install -vDm755 target/release/cosmic-settings /usr/bin/cosmic-settings &&

install -vDm644 target/xdgen/*.desktop /usr/share/applications/ &&

install -vDm644 resources/com.system76.CosmicSettings.metainfo.xml \
  /usr/share/metainfo/ &&

cp -rv resources/icons/* /usr/share/icons/hicolor/ &&

install -vDm644 resources/polkit-1/rules.d/cosmic-settings.rules \
  /usr/share/polkit-1/rules.d/ &&

install -vDm644 resources/polkit-1/actions/com.system76.CosmicSettings.Users.policy \
  /usr/share/polkit-1/actions/
