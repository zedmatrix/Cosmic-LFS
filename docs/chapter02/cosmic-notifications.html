Cosmic-notifications Dependencies

Required

rustc, cargo-c, intltool, wayland, libxkbcommon, and cosmic-icons

2.15.1. Installation of Cosmic-notifications

Prepare Cosmic-notifications for compilation:

Fetch the dependencies, ensuring the exact versions recorded in the existing Cargo.lock file are used: 

cargo fetch --locked

To Compile the Package, issue: 

cargo build --profile release

Now Install the Package, issue: 

install -vDm755 target/release/cosmic-notifications \
        /usr/bin/cosmic-notifications
