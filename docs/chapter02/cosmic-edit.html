Cosmic-edit Dependencies

Required

rustc, cargo-c, libxkbcommon, wayland, cosmic-icons, glib, and gobject-introspection

2.9.1. Installation of Cosmic-edit

Prepare Cosmic-edit for compilation:

Fetch the dependencies, ensuring the exact versions recorded in the existing Cargo.lock file are used: 

cargo fetch --locked

To Compile the Package, issue: 

export VERGEN_GIT_COMMIT_DATE='Tue Oct 20 13:45:44 2026 -0600'
export VERGEN_GIT_SHA=4ac1cc84f784d4f89327f3d3459af2633ceb4f12
cargo build --release

Now Install the Package, issue: 

install -vDm755 target/release/cosmic-edit /usr/bin/cosmic-edit &&

install -vDm644 target/xdgen/com.system76.CosmicEdit.desktop \
  /usr/share/applications/ &&

install -vDm644 target/xdgen/com.system76.CosmicEdit.metainfo.xml \
  /usr/share/metainfo &&

cp -rv res/icons/hicolor/* /usr/share/icons/hicolor/
unset VERGEN_GIT_COMMIT_DATE VERGEN_GIT_SHA
